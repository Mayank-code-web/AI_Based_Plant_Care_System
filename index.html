About the project

An educational prototype demonstrating how machine learning, text similarity, retrieval, and vision-language AI can support early plant-care decisions.

PythonStreamlit scikit-learnTF-IDF Groq APIFAISS / RAG

Important note

The local symptom and stress models use synthetic training data. Outputs are preliminary suggestions, not expert-confirmed diagnoses. AI photo analysis and chatbot features also depend on external API availability and configuration.

Use this project for learning and demonstration. For serious or persistent plant problems, consult a qualified horticulture or agricultural professional.
